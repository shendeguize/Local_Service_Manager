# @shendeguize/local-sm

This package is a thin npm launcher for the LocalSM Python CLI. It does not
bundle Python or the LocalSM wheel; it uses `uvx` to run the published
`local-sm` version.

Install uv first, then run:

```sh
npx @shendeguize/local-sm --version
```

For the full LocalSM documentation, see the
[repository README](https://github.com/shendeguize/Local_Service_Manager).
